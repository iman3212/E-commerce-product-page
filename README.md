# E-commerce Product Page 🛍️

A simple and responsive e-commerce product page built with HTML, CSS, and JavaScript.

This project focuses on presenting a product with a clean layout and a user-friendly interface.

## ✨ Features

- Product details and images
- Simple and clean design
- Responsive layout
- Interactive user interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/iman3212/E-commerce-product-page.git
```

Navigate to the project directory:

```bash
cd E-commerce-product-page
```

Open `index.html` in your browser to view the website.
